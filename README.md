## Малые и средние предприятия лёгкой промышленности России (2016–2023)

## Ключевые результаты

- **Контрольное задание (топ-3 региона по средней выручке):** Республика Алтай — 161 млн ₽, Карачаево-Черкесия — 121 млн ₽, Магаданская область — 120 млн ₽ (среднее по топ-3 — **134 млн ₽** против ~19 млн по стране). Это эффект «компаний-гигантов в малых регионах» (медианные выручки там 1–9 млн ₽). Устойчивый рейтинг по **суммарной** выручке: **Москва (962 млрд ₽) → Ивановская область (414 млрд ₽) → МО (392 млрд ₽)**.
- **ML-прогноз выручки компании (год N+1):** CatBoost — **R² = 0.72**, MAE = 0.29 порядка (≈ ×2 по рублям); RandomForest — R² = 0.71. Главные факторы — выручка и расходы текущего года.
- **Прогноз сектора:** тренд **+47.2 млрд ₽/год**, ожидаемая выручка 2023 г. ≈ **856 ± 111 млрд ₽**.
- **Корреляции:** выручка ↔ расходы r = 0.92; выручка ↔ численность r = 0.66, эластичность ≈ 1 (рост упирается в кадры).
- **Столичный перекос:** Москва + СПб — 34.5% выручки сектора при 26.5% компаний.
- **Неочевидная история:** география выручки (столицы) ≠ география занятости (текстильные регионы: Ивановская — «русский Манчестер» — 2-е место по выручке). Поддержка МСП «по месту выручки» укрепит офисы, а не цеха.

## Правовой контур

- **152-ФЗ:** набор не содержит ПДн физлиц (ИП исключены на этапе публикации); идентификаторы юрлиц обезличены (SHA-256 с солью), адреса агрегированы до населённого пункта.
- **242-ФЗ:** все вычисления и хранение — на локальной инфраструктуре, данные не покидают периметр.
- **ГОСТ Р ИСО/МЭК 27001:** журнал аудита операций пайплайна (загружен в СУБД), контроль целостности данных (контрольные суммы витрины против источника).
